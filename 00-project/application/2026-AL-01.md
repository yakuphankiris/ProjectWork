# Design and Performance Optimization of a Relational Database for an Electric Vehicle Charging Network with AI Support

## My interpretation of the brief
The project focuses on designing and implementing a relational database for an electric vehicle charging network and evaluating its performance with realistic, reproducible test data. The model must cover charging stations, charging points, users, vehicles, reservations, charging sessions, consumption measurements, tariffs, payments, and technical events. The main work involves enforcing data integrity, developing complex SQL queries, analyzing execution plans, and measuring the effects of indexing and query optimization. AI-generated suggestions must also be reviewed and compared with independently developed solutions. A complete management application is outside the mandatory scope.

## Why I am a good fit for this project
I have previously completed a similar project and am currently working on another related project. I have intermediate experience with C#, Microsoft SQL Server, and the .NET Framework, which I believe provides a useful foundation for this work. I would like to apply this knowledge to a database-focused project and improve my understanding of how schema design, SQL queries, and indexes affect performance as the amount of data grows.

## Relevant experience and background
My previous and ongoing project work has given me experience with C#, the .NET Framework, and Microsoft SQL Server. I expect to use my SQL Server knowledge for the database implementation and my C#/.NET background to develop test-data generation and performance-measurement tools. The project would allow me to build on this experience while learning more about execution plans and systematic optimization.

## Proposed approach
I would use Microsoft SQL Server and T-SQL. I would first design a schema in at least third normal form with at least ten related tables, appropriate keys, integrity constraints, and database-side business logic. I would then develop a C# tool to generate reproducible test data and run repeatable performance measurements.

After preparing the required queries, I would record baseline execution plans, execution times, and I/O statistics. I would compare query rewrites and simple, composite, and filtered indexes where appropriate. For at least three selected queries, I would obtain AI-generated optimization suggestions, review their correctness and executability, and measure their performance against my own solutions. AI-generated statements would be reviewed before execution, and comparisons would check that query results remain correct.

## Initial plan
1. Define the charging-network processes, data-model assumptions, and measurement methodology.
2. Write the specification and implement the normalized schema, constraints, and at least one business-logic stored procedure or function.
3. Generate at least 100,000 charging sessions and one million timestamped measurement or status records reproducibly.
4. Develop at least ten complex SQL queries and record baseline measurements for at least five using execution plans, SET STATISTICS IO, and SET STATISTICS TIME.
5. Compare at least two optimization approaches and quantitatively evaluate improvements for the selected queries.
6. Evaluate AI suggestions for at least three queries and document the results, limitations, and steps required to reproduce the experiments.

## Additional information
I plan to keep the schema, queries, data generator, measurement tools, and documentation in a Git repository. Any external AI service would be used with synthetic examples and without credentials or personal data in prompts or repository files. My main aim is to produce a reproducible comparison that explains both the benefits and tradeoffs of each optimization.
